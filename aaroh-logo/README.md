# Aaroh Entertainment Limited: logo asset pack

The mark is **Seven Swaras**: seven dots rising from bottom left to top right, each a little
larger than the last, like the seven notes of the ascending scale (Sa Re Ga Ma Pa Dha Ni).
Six are teal; the seventh, the largest, is gold.

Everything here is generated by `scripts/build.mjs`. To change a colour or the geometry, edit
the **BRAND** section at the top of that file and run:

```bash
npm install   # once
npm run build
```

The build cleans and rewrites every folder below except `fonts/` and `scripts/`, and stops with
an error if any transparent PNG has ink touching its edge, which would mean something is clipped.

## What each file is for

### `svg/`: master artwork (vector, text outlined, no fonts needed)

| File                     | Use                                                                               |
| ------------------------ | --------------------------------------------------------------------------------- |
| `aaroh-icon-*.svg`       | The mark alone: avatars, app icons, stamps, watermarks                            |
| `aaroh-horizontal-*.svg` | Icon left, name right: website header, letterhead, email signature, documents     |
| `aaroh-stacked-*.svg`    | Icon above the name: square and centred layouts, posters, merchandise             |
| `aaroh-icon-small-*.svg` | Four-dot variant for 24 px and below (favicons, tiny UI). No clear space built in |

Each comes in four colour versions:

| Suffix         | Colours                                 | Use on                                  |
| -------------- | --------------------------------------- | --------------------------------------- |
| `-full-colour` | Teal dots and text, Swara Gold top dot  | Light backgrounds (ivory, white)        |
| `-reversed`    | Ivory dots and text, Light Gold top dot | Dark backgrounds (teal, black)          |
| `-black`       | Everything #111111                      | One-colour print, fax, stamps           |
| `-white`       | Everything #FFFFFF                      | One-colour on dark or photos, embossing |

All lockup SVGs include the clear space, so placing the file edge to edge with other content
keeps the right margin automatically.

### `png/`: the same artwork as transparent PNGs

`png/icon/`, `png/horizontal/`, `png/stacked/`: every lockup and colour version at 512, 1024 and
2048 px wide, e.g. `png/horizontal/aaroh-horizontal-reversed-1024.png`. Use the SVGs where you can
(websites, print); PNGs are for tools that cannot take SVG (Office, Canva, some social sites).

### `app-icon/`

| File                      | Size      | Use                                               |
| ------------------------- | --------- | ------------------------------------------------- |
| `aaroh-app-icon-1024.png` | 1024×1024 | App stores and master app icon                    |
| `apple-touch-icon.png`    | 180×180   | iOS home screen (`<link rel="apple-touch-icon">`) |
| `android-chrome-192.png`  | 192×192   | Android / PWA manifest                            |
| `android-chrome-512.png`  | 512×512   | Android / PWA manifest, splash screen             |
| `aaroh-app-icon.svg`      | vector    | Source of the above                               |

Teal background, reversed icon at 70% of the width. iOS and Android round the corners
themselves, so the files are square. They are not "maskable": a circular Android mask would trim
the edge of the gold dot, so do not declare `"purpose": "maskable"` for them.

### `favicon/`

- `favicon.svg`: the small four-dot variant. Teal and gold, switching to ivory and light gold
  when the browser is in dark mode.
- `favicon.ico`: 16, 32 and 48 px, for older browsers and Windows.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`: the images inside the `.ico`.

```html
<link rel="icon" href="/favicon.ico" sizes="any" />
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
```

### `social/`

| File                                 | Size      | Use                                                                                                          |
| ------------------------------------ | --------- | ------------------------------------------------------------------------------------------------------------ |
| `aaroh-profile-1080.png`             | 1080×1080 | Profile picture everywhere (Instagram, YouTube, LinkedIn, TikTok, X). Safe for circular crops                |
| `aaroh-youtube-banner-2560x1440.png` | 2560×1440 | YouTube channel art; the logo sits inside YouTube's 1546×423 safe area, so it shows on TV, desktop and phone |
| `aaroh-linkedin-banner-1584x396.png` | 1584×396  | LinkedIn banner; the logo is centred and kept clear of the lower left, where the profile photo overlaps      |

### `brand-sheet/aaroh-brand-sheet.pdf`

Two A4 landscape pages: the mark, lockups, colours (HEX, RGB, CMYK), typefaces, clear space,
minimum sizes and do / don't examples. Send it to anyone designing with the logo.

### `source/`

- `aaroh-horizontal-editable.svg`, `aaroh-stacked-editable.svg`: the lockups with **live text**,
  for editing in Illustrator, Figma or Inkscape. They need the two fonts in `fonts/` installed.
  Outline the text again before sending files out (or just re-run the build).
- `geometry.json`: the dot positions, sizes, clear space and colours as data.

### Website files (`../client/public/`)

The build also writes the files the Aaroh website uses, so the site stays in step with the pack:
`brand/icon.svg` (the icon without clear space, shown beside the name in the header; its
colours are CSS variables the site sets), `brand/favicon.svg`, `favicon.ico`, `brand/apple-touch-icon.png`, `brand/icon-192.png`,
`brand/icon-512.png`, `brand/og-default.png` (1200×630 share image) and `site.webmanifest`.
Rebuild the site after running the build.

### `fonts/`

Cormorant Garamond SemiBold, Jost Medium and Jost Regular (used in the brand sheet), downloaded
from Google Fonts, with their SIL Open Font License files (`OFL-*.txt`). Both families are free
for commercial use, including in a logo.

The CMYK values are a straight conversion from RGB. Ask the printer to match the HEX values
(or a Pantone they propose) on a proof before a large run.

## Fonts

- **AAROH**: Cormorant Garamond SemiBold (600), letter-spacing 8% of the font size.
- **ENTERTAINMENT**: Jost Medium (500), capitals, letter-spacing 68% of its font size, sized so
  it is exactly as wide as AAROH.
- Gap between the lines: 30% of the AAROH cap height.

## Usage rules

- **Clear space**: keep a margin equal to the gold dot's diameter on every side. The files
  already include it.
- **Minimum size**: icon 16 px on screen / 6 mm in print (use the small four-dot variant at
  24 px and below); horizontal lockup 120 px wide on screen / 30 mm in print.
- **Pick the version for the background**: full colour on light, reversed on dark, black or
  white when only one colour is possible. On photographs, use whichever reads clearly, usually
  white or reversed.
- **Don't**: recolour it, stretch or squash it, rotate it, add shadows, glows or outlines,
  change the order, size or spacing of the dots, or reset the name in another font.
